# Спецификация: WP-01

## Требование FR-04: Получение занятия по ID
- **WHEN** клиент делает `GET /lessons/{lesson_id}` для существующего занятия
- **THEN** возвращается статус `200 OK` и тело `Lesson` (включая `cancel_reason`); время в UTC с суффиксом `Z`.
- **WHEN** клиент запрашивает несуществующий `lesson_id`
- **THEN** возвращается `404` с `{"error": {"code": "NOT_FOUND", "message": "...", "details": {}}}`.

## Требование FR-11: Получение группы по ID
- **WHEN** клиент делает `GET /groups/{group_id}` для существующей группы
- **THEN** возвращается статус `200 OK` с полями `id`, `name`, `size`.
- **WHEN** запрашивается несуществующая группа
- **THEN** возвращается `404` с `{"error": {"code": "NOT_FOUND", "message": "...", "details": {}}}`.

## Требование NFR-02: Воспроизводимость миграций
- **WHEN** применяется команда `alembic upgrade head` на чистой базе данных PostgreSQL 16
- **THEN** миграции отрабатывают успешно без ошибок рассинхронизации схемы.

## Требование NFR-03: Детерминированный Seed и тестовое время
- **WHEN** запущено приложение с `SEED_ON_START=1` или вызвана команда `just seed` (в том числе повторно)
- **THEN** в БД фиксированный seed из `seed/` без дубликатов (3 группы, 8 занятий).
- **WHEN** при `TEST_MODE=1` вызывается `POST /__test/reset`
- **THEN** ответ `204`, данные возвращены к seed, время `Clock` не изменилось.
