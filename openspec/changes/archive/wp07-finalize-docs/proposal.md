# Предложение: WP-07 Финализация документации

## Цель

Закрыть NFR-05 и NFR-06: добить README по шаблону (AI notes, Не сделано, журнал времени), перенести завершённые OpenSpec changes в `archive/`, убедиться что `just check` и `just lint-commits` зелёные.

## Trade-offs и альтернативы

- **Выбранный подход:** документационный пакет без новых API; Should/Could (WP-08…10) зафиксировать в «Не сделано». Archive всех закрытых Must-пакетов до сдачи.
- **Альтернатива:** оставить changes в `openspec/changes/` — отвергнута: WP-07 и `openspec/config.yaml` требуют архив.
