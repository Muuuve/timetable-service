# Технический дизайн: WP-02

- **Слой клиента:** модуль вроде `src/app/clients/people.py` (или `app/people_client.py`). HTTP и маппинг ошибок заглушки; предметные BR-01…BR-07 сюда не входят (WP-03).
- **Параллелизм:** для очного занятия — `asyncio.gather` на профиль, availability и classroom; для `ONLINE` аудиторию не запрашивать.
- **Таймаут:** каждый вызов с `STUB_TIMEOUT_MS` (из settings); при превышении — исключение/ошибка → `504 UPSTREAM_TIMEOUT`.
- **Маппинг отказов заглушки:**
  - 404 → сущность не найдена (для WP-03 станет частью BR-03 / кодов задания);
  - 5xx → `502 UPSTREAM_UNAVAILABLE`;
  - таймаут/сеть → `504 UPSTREAM_TIMEOUT`.
- **Тест:** фейковый клиент с искусственной задержкой ~300 мс на вызов; параллельный путь заметно быстрее последовательного; без реального people-stub и сети.
