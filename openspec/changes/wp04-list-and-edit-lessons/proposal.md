# Предложение: WP-04 Список и изменение занятий

## Цель
Реализовать `GET /lessons` (FR-03) со фильтрами, сортировкой и пагинацией и `PATCH /lessons/{lesson_id}` (FR-05): частичное изменение только в статусе `PLANNED` с повторной проверкой BR-01…BR-07. Опереться на домен и сервис из WP-03 (`exclude_lesson_id` для PATCH).

## Trade-offs и альтернативы
- **Выбранный подход:** список — запрос к БД с фильтрами в SQL; PATCH — загрузка занятия, проверка статуса, слияние полей, тот же пайплайн правил что у create (people-stub + `evaluate_lesson_rules`), затем UPDATE. Статус через PATCH не меняется.
- **Альтернатива:** отдельный набор правил для PATCH — отвергнута: задание требует те же BR-01…BR-07.
